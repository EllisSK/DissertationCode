# Setup
Three CSV datasets are required to run this code, please contact ellissinclairkent@gmail.com for these datasets.
The script should be run with the analysis flag first, then either the visualisation or the solver flags

# Analysis
uv run main.py --analysis

# Visualisations
uv run main.py --visualisation

# Solver
uv run main.py --solver
